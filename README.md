# 🌿 FloraNest

## Introduction

FloraNest is an AI-powered plant e-commerce platform developed as a Full Stack Web Development course project.

## Technology Stack

### Backend
- Spring Boot
- MyBatis
- MySQL

### Frontend
- Vue 3
- Element Plus
- Axios
- Pinia
- Vue-router

### Development Tools
- IntelliJ IDEA
- VS Code
- Maven
- Git
- Postman
